# 🤖 بوت كويستر (Quester Bot)

بوت ديسكورد خفيف وسريع، وظيفته:
1. **📢 منبه للمهام الجديدة (Quest Notifier):** فحص ديسكورد دورياً ونشر رسالة Embed احترافية في روم السيرفر تلقائياً أول ما تنزل مهمة جديدة (شاملة الصورة، الجوائز، المطلوب، تاريخ الانتهاء، ورابط الحل على موقع Quester).
2. **🎮 بث الشاشة والمشاهدة التلقائية (`/stream`):** لتجميع ساعات شارة البث (Phenomenon) في الخلفية.

---


## 🛠️ أوامر السلاش المتاحة:
* `/checkquests` ➔ فحص ونشر المهام الجديدة في الروم فوراً يدوياً (للتجربة).
* `/stream start` ➔ بدء جلسة بث شاشة وهمية ومتابعة من حساب مشاهد.
* `/stream stop` ➔ إيقاف جلسة البث.
